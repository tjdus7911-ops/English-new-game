## 꼭 필요한 신규 에셋
1. **빈 거실 바탕(1장)** — v3와 같은 구도에서 바꿀 가구·소품만 지운 그림. 가구가 그림에 합쳐져 있어서 이게 없으면 모양이 다른 디자인으로 교체할 수 없음
2. **같은 각도·조명의 개별 오브젝트** — 약 29개 오브젝트 × 3종 ≈ 87개 중 v3 원본·시트 재사용 ≈ 25개를 빼면 **약 60개 신규** + 새 위치 오브젝트(거울·조각상·샹들리에 등)
3. **이전 상태 3장** — 고장 난 창틀·몰딩·계단 난간
4. 소파 천을 걷은 뒤의 '낡은 소파' 1장

## 제작 방법 제안
- **추천: 이미지 편집 모델로 v3를 직접 편집** — Figma Weave(이미지 편집 모델)에서 (1) v3에서 가구만 지운 빈 거실, (2) v3의 해당 부분을 '같은 자리·같은 각도에서 다른 디자인'으로 바꾼 변형을 만든 뒤, 빈 거실과의 차이로 투명 오브젝트를 잘라낸다 → 원근·조명·화풍이 v3와 자동으로 일치
  - 필요 조치: Figma 계정을 Weave에 연결 (https://app.weavy.ai/settings?section=profile), 편집 모델 사용 크레딧
- **보조: Figma AI 텍스트 생성** — 화병·시계·촛대·화분·조각상처럼 작고 대칭인 소품은 마젠타 배경 시트로 생성해도 각도 차이가 거의 안 보임 (지금 바로 가능, 크레딧 사용)
- 큰 가구·빈 거실은 텍스트 생성으로는 v3 구도를 유지할 수 없어 권장하지 않음

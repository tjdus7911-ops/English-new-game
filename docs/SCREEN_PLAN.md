# 화면 구성안 (제안 · 확정 전)

배경은 이 게임 전용으로 새로 제작합니다. 다른 프로젝트의 배경·UI는 쓰지 않습니다.

## 화면 흐름

```
[알섬 홈] ─┬─ 펫 터치 → 행동 메뉴(쓰다듬기·먹이·놀기·상태) → 반응 애니메이션
           ├─ [부화장] 알 목록 → 알 선택 → 부화 연출 → 새 펫 → 도감 등록
           ├─ [내 펫] 목록 → 상세(레벨·친밀도·상태·기록) → 진화 → 진화 연출
           ├─ [도감] 9속성 × 3종 (미획득은 실루엣) → 상세(성장 라인업)
           └─ 근접 교감(친밀도 해금) → 클로즈업 연출
```

## 1. 알섬 홈 (메인)
- 화면을 꽉 채우는 펫 공간. 바닥 영역 안에서 펫 1~3마리가 자유롭게 돌아다님.
- 상단: 코인 · 먹이 · 알 개수. 하단: 부화장 · 내 펫 · 도감 · 설정.
- 펫 위 작은 말풍선으로 감정 표시. 배고픔·졸림 등 상태가 낮으면 아이콘으로 알림.

## 2. 부화장
- 보유 알을 둥지에 나란히 표시. 알 탭 → 부화 연출(등장 → 흔들림 → 균열 → 속성 이펙트 → 깨짐 → 펫 등장 → 기쁨 모션 → 도감 등록 카드).

## 3. 내 펫 / 상세
- 카드 목록(이름 · 속성 · 단계 · Lv). 상세에서 경험치·친밀도·배부름·기운, 획득일, 성장 기록, 진화 조건 진행도, 홈에 내보내기.

## 4. 도감
- 속성 탭 9개 × 3종. 획득: 단계별 이미지·획득일·최고 단계. 미획득: 실루엣 + "???".

## 배경 방향 (택1 요청)
| 안 | 분위기 | 장점 |
|---|---|---|
| A. 하늘섬 초원 | 구름 위 둥근 풀밭 섬, 가운데 큰 알 둥지 | 게임 이름과 맞음, 27종 모두 어울림 |
| B. 아늑한 펫 방 | 따뜻한 원목 방, 쿠션·밥그릇·장난감 | 쓰다듬기·먹이 장면이 자연스러움 |
| C. 속성 정원 | 9속성 구역(불·물·숲…)이 둥글게 이어진 정원 | 속성 수집감, 확장(구역 해금) 쉬움 |

어느 안이든 펫 에셋과 같은 **고품질 3D 카툰** 스타일, 가로·세로 모두 쓸 수 있도록 바닥 영역을 중앙에 넓게 둡니다. 확정되면 배경을 새로 생성하고 이동 가능 영역(바닥 다각형)·장애물 데이터를 배경 전용으로 만듭니다.

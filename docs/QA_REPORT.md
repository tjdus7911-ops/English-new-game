# QA 보고서 — 혼자영어(가칭) MVP

- 실행일: 2026-11-03 (KST)
- 환경: Linux 클라우드 컨테이너 2 vCPU, Node 22.23, Chromium 1243(Playwright 1.63, headless, 모바일 에뮬레이션 390×844 DPR2, 터치), Vite 6 production build + `vite preview`

## 4. 콘텐츠 검수 상태

| 상태 | 수 |
|---|---|
| 자동 검증 완료 | 문법 10단원, 대화 20편, 표현 150개, 드라마 3편, 단어 300 |
| 교육 전문가 검수 완료 | **0** |
| 공개 가능 표시 | 0 (테스트로 강제) |

자동 검증 항목: 정답·해설 100%, 정답이 선택지에 존재, 오답 선택지가 정답으로 채점되지 않음(복수 정답 오류 탐지 — 실제로 표현 듣기 문제 1건 발견·수정), 단어 배열 조각 일치, 받아쓰기 정답이 실제 음성 문장에 포함, 문항 id 중복 0, 선행 단원 유효.
자동 검증으로 보장되지 않는 것: 문법 설명의 교육적 정확성, 번역 자연스러움, CEFR 적합성, IPA 표기(CMU 사전 자동 변환), TTS 발음 품질(사람이 들어 보지 않음).

## 5. 남은 문제와 수정 방안

| 우선순위 | 문제 | 수정 방안 |
|---|---|---|
| High(출시 전) | 교육 콘텐츠 전문가 검수 미진행 | 단원별 검수 → `reviewStatus` 갱신 |
| High(출시 전) | 실제 브라우저 STT(Chrome·Safari·Android WebView) 미검증 | HTTPS 배포 후 실기기 테스트, 지원 범위 문서화 |
| Medium | 음성이 합성 음성(Piper·LibriTTS). 요청서의 '원어민 예시 음성'과 다름 | 원어민 녹음 또는 상용 TTS로 교체 (`scripts/generate_audio.py` 경로 그대로 재생성) |
| Medium | 브랜드 컬러 #E9513B 버튼 위 흰 글자 대비 약 3.6:1 (WCAG AA 4.5:1 미달, Lighthouse 홈 96점 원인) | 디자인 결정 필요: 버튼 배경을 #B3361F로 어둡게 하거나 버튼 글자를 18.66px bold 이상으로 |
| Medium | 실기기 성능·INP 미측정 | 저사양 Android에서 측정 |
| Low | 로컬 저장만 지원 → 브라우저 데이터 삭제·기기 변경 시 소실 (앱 내 고지함) | Supabase 동기화 |
| Low | 일러스트가 코드 기반 단순 SVG — 참고 이미지 수준의 회화풍 아님 | 디자이너 에셋으로 교체(같은 assetPath 키 사용) |

## 6. 미구현 / 범위 외 (명시)

온실·호숫가·작업실·테라스 실제 플레이(잠금 안내만), 집 Lv.4~5, A2~B2 정규 콘텐츠, 발음 정확도·강세·억양·유창성 평가와 AI 회화·역할극('준비 중' 표시), 기기 푸시 알림(앱 내부 알림만), 자유 영작 의미 평가, 클라우드 동기화, 자유 배치(슬롯형만).

# 거실 리모델링 단계 상태 (시안 A v3 기준) — 시안 단계

> 상태: **게임 적용 완료 (2026-11-04)**. 게임 화면은 확정 v3 그림을 그대로 쓰고, 미완료 미션의 이전 상태 레이어를 겹쳐 보여 줍니다.
> Figma: `A2. 시안 A · 주요 화면 시안` → `리모델링 단계 비교 · STEP 0→4` (node 38:2), 원본 해상도 1536×864

## 원칙

- 확정된 **시안 A v3**(node 34:2)를 STEP 4로 두고, 이전 단계는 **v3 위에 상태 레이어만 얹어서 거꾸로 만든 것**입니다. 집 전체를 새로 생성하거나 구조를 바꾸지 않았기 때문에 카메라·방 배치·크기가 모든 단계에서 픽셀 단위로 같습니다.
- 레이어 종류
  1. **영역 색보정 레이어**: v3 이미지 자신을 해당 영역만 마스크해서 다시 보정합니다(바랜 벽지, 바닥 먼지·마모, 먼지 쌓인 테이블·계단, 꺼진 조명·벽난로).
  2. **개별 스프라이트**: 시안 A 에셋 시트에서 마젠타를 제거한 투명 PNG입니다(천 덮인 소파, 낡은 안락의자, 상자, 먼지·신문 더미, 낙엽, 말린 카펫, 거미줄, 나무 상자). Figma `A0` 페이지 하단 `keyed/*`.
  3. **벡터 레이어**: 벽지 벗겨짐, 균열, 더러운 유리, 재. 게임에서는 같은 위치의 개별 스프라이트로 바꿉니다.
- 어둡거나 공포스럽지 않게 하려고 전체 밝기는 낮추지 않았고, 채도와 색온도만 낮춰 "오래된" 느낌을 냈습니다.

## 단계 정의와 레이어

| 단계 | 화면 상태 | 켜진 상태 레이어 |
|---|---|---|
| STEP 0 · BEFORE (최초 진입) | 바닥 먼지·쓰레기, 바래고 벗겨진 벽지, 먼지 쌓인 가구, 더러운 창문, 꺼진 벽난로·조명, 천 덮인 소파, 찢어진 안락의자, 거미줄 | 전부 |
| STEP 1 · 청소 완료 | 쓰레기·먼지·거미줄 제거, 창문 닦음(햇빛 회복) | 벽지 손상, 바닥 마모, 꺼진 벽난로·조명, 낡은 가구 |
| STEP 2 · 수리 완료 | 벽지·균열·바닥 복구, 벽난로 수리·점화 | 낡은 가구(천 덮인 소파, 안락의자 2), 조명 꺼짐 |
| STEP 3 · 인테리어 진행 | 소파·테이블·러그·조명 배치, 안락의자 1개 교체 | 교체 대기 중인 안락의자 1 |
| STEP 4 · 완료 (v3) | 확정 디자인 | 없음 |

## 게임 연동안 (승인 후 적용)

미션 1개 = 상태 레이어 묶음 1개로, 미션을 완료하면 해당 레이어만 제거하거나 교체합니다(저장 데이터 `mansion.renovations` 기준이라 재접속해도 유지).

| 단계 | 미션(별) | 제거/교체되는 레이어 |
|---|---|---|
| 청소 | R01 바닥 청소(1) · R02 창문·거미줄 청소(1) | 쓰레기·먼지 스프라이트, 바닥 먼지 / 더러운 유리, 거미줄 |
| 수리 | R03 벽지 교체(2, 3종) · R04 바닥 수리(2, 3종) · R05 벽난로 수리(1) | 바랜 벽지·벗겨짐 → 선택 벽지 / 바닥 마모 → 선택 바닥재 / 꺼진 벽난로 → 점화 |
| 인테리어 | R06 소파(2, 3종) · R07 안락의자(1, 3종) · R08 테이블·러그(1, 3종) · R09 조명·장식(2, 3종) | 천 덮인 소파·낡은 의자 → 선택 가구, 꺼진 조명 → 켜짐 |
| 완료 | R10 거실 완성(1) | — → 다음 공간(주방) 해금 |

합계 14별은 그대로 유지합니다. 현재 스토리 트리거(소파 밑 편지, 벽 속 문양, 의자 속 사진)는 해당 미션에 다시 연결합니다.

## 게임 적용 방식

- 게임 화면은 키아트 한 장을 쓰지 않고, 시안 A 개별 에셋(벽·바닥 텍스처, 벽난로·창·문·계단·책장, 가구, 캐릭터)을 기존 아이소메트릭 맵 엔진에 배치해서 v3 구성을 재현합니다. 그래서 오브젝트마다 상태를 따로 바꿀 수 있습니다.
- **차단 사항**: 이 작업 환경에서 `www.figma.com`·`mcp.figma.com` 접속이 막혀 있어서 Figma 에셋을 저장소로 아직 내려받지 못했습니다. 허용되면 `scripts/process_assets.py`(마젠타 제거·트림·앵커)로 처리해서 `public/assets/game/a/*` 에 넣습니다.

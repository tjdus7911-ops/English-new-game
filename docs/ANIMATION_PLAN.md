# 애니메이션 구현 계획

## 현재 에셋으로 할 수 있는 것
Figma 에셋은 **모션당 키포즈 1장**(근접 교감 4장, 불꽃 여우 진화 4장)입니다. 프레임 단위 원화가 아니므로:

1. **포즈 교체** — 상태가 바뀌면 해당 키포즈로 전환 (짧은 크로스페이드 120ms).
2. **절차적 트랙** — 포즈 위에 숨쉬기(세로 1~2% 스케일), 걸음 바운스, 달리기 기울기, 점프 포물선, 흔들림, 졸음 들썩임 등을 코드로 얹음 (`motions.ts` 의 `track`).
3. **이펙트 레이어** — 하트·반짝이·Zzz·속성 파티클·먼지.

실제 프레임 시트(걷기 8프레임 등)가 생기면 `motions.ts` 의 `frames` 에 프레임만 추가하면 같은 런타임으로 재생됩니다.

## 상태 기반 애니메이션 시스템
- 순수 TypeScript 상태 머신(화면·저장과 분리, 단위 테스트 가능).
- 반복 모션(idle·walk·run·sit·sleep·follow)과 일회성 모션(감정·상호작용)을 구분.
- 일회성 모션이 끝나면 `next` 또는 idle 로 복귀. 우선순위(priority)가 높은 요청만 현재 모션을 끊음 → 동시 충돌 없음.
- 자는 펫 터치 → wake_up → yawn → idle.
- 행동 AI: idle 대기 후 확률적으로 걷기/달리기/앉기/둘러보기/특수 동작, 기운이 낮으면 drowsy → sleep. 확률은 설정값.

## 이동
- 배경별 바닥 다각형 + 장애물 데이터 → 격자 길찾기(A*). 펫 크기(몸집·단계)만큼 장애물을 넓혀 통과 방지.
- 원근: 화면 아래로 올수록 크게, 겹침 순서는 발밑 y 기준.
- 이동 방향에 따라 좌우 반전, 방향 전환 시 turn 포즈.

## 연출
- **부화**: 알 이미지 + 흔들림·균열(SVG)·속성 색 파티클·두 조각으로 깨짐 → 펫 happy.
- **진화**: 빛 기둥 → 실루엣(밝기 필터) → 확대·폭발 → 다음 단계 포즈 → level_up. 불꽃 여우 S2→S3 은 전용 키프레임 4장 사용.
- **근접 교감**: 화면 중앙 둥근 프레임에 cl_* 4장 순서 재생(다가오기 → 클로즈업 → 볼 비비기 → 뒤로 물러나기).

## 성능
- 펫·단계별 아틀라스 1장(약 0.2~0.5MB) — 화면에 나온 펫만 로드.
- DOM + CSS transform(GPU) 렌더, requestAnimationFrame 하나로 모든 펫 갱신, 화면 밖·백그라운드 탭에서는 정지.

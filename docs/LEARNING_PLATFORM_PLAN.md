## 2. 중복·충돌과 해결안

1. **재화 2종 (마을 별 vs 저택 별)** → 화면에 보이는 '별'은 **저택 별 원장 하나**로 통일합니다. 기존 마을 별 데이터는 지우지 않고 '이전 마을 포인트'로 보관하며, 기존 마을·집 꾸미기 화면은 MY › '이전 학습 마을'에서 계속 열 수 있습니다.
2. **기존 퀘스트 → 오늘의 영어 퀘스트** → 새 퀘스트 데이터(일일 3개 + 전부 완료 시 보너스 ★1, 날짜 키로 중복 방지)를 따로 둡니다. 기존 퀘스트 수령 기록은 보존하고 화면에서만 대체합니다.
3. **보상 규칙** → 요청서 표대로 `config/rewards.ts` 설정 데이터로 분리합니다. 세트 id마다 **최초 완료 1회만** 별을 주고, 정답률 기준(60%)과 문항당 최소 응답 시간(1.2초, 연속 3회 미만이면 '무작위 클릭' 의심 → 보상 보류)을 둡니다. 반복 학습은 기록만 갱신합니다. 기존 스테이지 최초 통과 기록(earn:stage:*)은 그대로 인정합니다.
4. **리모델링 11작업(20별)** → 새 작업 id로 재정의하고, **기존 저장 데이터 마이그레이션 표**로 이미 완료한 작업과 선택한 가구를 옮깁니다(R01→청소 3종 완료, R02→벽지 제거+새 벽지, R04→바닥 수리, R03·R05~R09→해당 가구, 사용한 별은 원장에 그대로 남김). 스토리 트리거(소파 밑 편지, 벽 속 문양, 의자 속 사진)는 대응 작업에 다시 연결합니다.
5. **화면 방향 vs 하단 내비게이션** → 홈(저택)은 가로형 정책을 유지하므로 **가로 홈에는 얇은 하단 탭(52px, 반투명 양피지)**, 세로 학습 화면에는 일반 하단 탭을 씁니다. 문제 풀이·동화 읽기·음성 학습처럼 집중이 필요한 화면에서는 숨깁니다. (대안: 가로 홈만 좌측 세로 레일)
6. **시안 A 에셋** → 게임 화면 적용은 여전히 Figma 다운로드 차단(`www.figma.com`) 때문에 대기 중입니다. 학습 화면은 시안 A 색·폰트 토큰을 CSS로 적용하므로 에셋 없이도 구현할 수 있습니다.

## 3. IA

```
하단 탭 (집중 화면에서는 숨김)
├─ 홈 (가로) ─ 집 전체 조망 · 챕터/공간명 · ★ · 설정
│   ├─ 리모델링 미션 바로가기 → 퀘스트 › 리모델링 탭
│   ├─ 오늘의 퀘스트 바로가기 → 퀘스트 › 영어 퀘스트 탭
│   ├─ 공간 터치 → 카메라 확대 (화면 전환 없음)
│   └─ 가구 디자인 선택(3종 미리보기) · 스토리 · 단서
├─ 영어 학습 (세로)
│   ├─ 오늘의 학습 진행률 · 이어서 학습하기 · 검색
│   ├─ 영단어 ─ 레벨(초급 A1 / 중급 A2~B1 / 고급 B2~C1) · 주제 필터 · 검색 → 목록 → 상세 → 학습(카드·뜻·철자·빈칸·오답 복습)
│   ├─ 문법 ─ 초급/중급/고급 → 단원(개념→예문→해석→핵심 정리→연습→오답 해설→완료)
│   ├─ 동화책 도서관 ─ 난이도별 목록(표지·시간·진행률) → 읽기(번역 토글·문장 음성·단어 뜻·단어 저장·위치 저장) → 독해 퀴즈
│   ├─ 영작 ─ 레벨·상황 → 한국어 제시 → 입력 → 정답 예시·문법 설명·자연스러운 표현 → 다시 쓰기
│   ├─ 리스닝 ─ 레벨·상황 → 재생(반복·속도) → 문제·받아쓰기 → 스크립트·해석·해설
│   ├─ 스피킹 ─ 레벨 → 문장 듣기 → 따라 말하기(마이크) → 인식 결과 비교 → 다시 말하기 / 대체 경로
│   ├─ 오답노트 · 저장한 단어·표현
├─ 퀘스트
│   ├─ [리모델링] 청소·수리·인테리어 작업(★ 소비) — 진행 가능/잠김/완료, ★ 부족 시 학습 안내
│   └─ [오늘의 영어] 영단어 10 · 문법 5 · 리스닝 5 (+전부 완료 ★1), 학습하러 가기
├─ 학습 기록 ─ 학습 일수 · 누적 시간 · 연속 일수 · 학습 단어 수 · 문법 진도 · 영역별 정답률 · 수준별 현황 · 최근 내역
└─ MY ─ 닉네임 · 학습 수준 · 학습 목표 · 알림 · 사운드 · 데이터 관리(로컬 저장 안내·초기화) · 이전 학습 마을 · 출처
```

## 4. 이동 플로우 (핵심 루프)

1. 홈(STEP 0 낡은 거실) → 리모델링 미션 → ★ 부족 → "학습하러 가기" → 영어 학습(세로 회전)
2. 영단어 초급 세트(10문제) 완료 → 정답률 확인 → **★+1 (세트 최초 완료)** → 오늘의 퀘스트 진행률 갱신
3. 퀘스트 3개 완료 → 보너스 ★1
4. 홈(가로 회전) → 리모델링 퀘스트 → 작업 확정(★ 차감 선커밋) → 캐릭터 작업 연출 → 해당 영역만 변경 → 스토리 이벤트
5. 거실 11작업 완료 → 다음 공간(주방) 해금 표시 (콘텐츠 준비 중)

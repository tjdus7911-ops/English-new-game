# 단어 숲 개편 — 난이도별 + 주제별 단어장

## 1. 현재 DB 분석 (분류 전)
- 단어 300개, 모두 A1 범위. 문법 10단원 × 30단어 (`src/content/vocab-data.ts`)
- 기존 필드: 단어 · 품사 · 뜻 · IPA · 한글 발음 · 예문 · 예문 해석 · 관련 문법 · 음성
- 의류 단어는 없음(쇼핑과 옷 = 사고팔기·가격·색깔 중심), 동물 단어는 fish 1개(자연과 동물 = 날씨·계절·자연 중심)

- 난이도: 왕초보 97 · 기초 203 · 초급/중급/고급 0 (화면에서 '준비 중', 진입해도 학습 불가 안내)

## 3. 학습 흐름
카테고리(난이도 또는 주제) → 챕터 → 단어 5개(상하 2단 카드) → 확인 퀴즈 1~2개 → 첫 완료 시 ★2 + 파트너 XP 3 (기존 '새 단어 10개마다 XP 5' 유지) · 복습 등록 · 퀘스트(영단어 10개) 진행 반영. 보던 단어 위치를 저장해 언제든 이어하기.

## 4. 단어 카드 (상하 2단)
- 상단 영어 카드: 단어 · IPA · 한글 발음 · 발음 듣기 · 품사 · 난이도 · 저장(☆). 뒤집히지 않음
- 하단 해석 카드: 처음엔 '뜻 확인하기'(뒷면) → 터치하면 뒤집혀 뜻 · 예문 · 번역 · 예문 듣기 · 짧은 설명 · 학습 상태. 다시 누르면 가림. 단어 이동 시 항상 뒷면으로 초기화
- 파트너(없으면 숲지기 등불)의 1~2문장 팁, 긴 설명은 '더 알아보기'(관련 문법 강의)로 분리
- 기존 문법 단원별 단어장은 '문법 단원별 단어장' 보조 메뉴로 유지 (같은 2단 카드 사용)
